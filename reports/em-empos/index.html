EM attribution — MCQ only, conditioned on the items that actually show EM

2026-07-31 · Qwen3.5-9B + sparse mask emmask_9b_midsp_lam3e-5/ep10 · jobs 1964355 / 1964356 / 1964448-50 / 1965050

What changed. All free-form (teacher-forced generative) EM attribution code and results were removed. Attribution is now MCQ-only, and restricted to probe items where the model actually picks the misaligned option. Scoring reuses em_eval_mcq's own machinery so "EM-positive" means exactly what the reported metric means.

Probe-diversity caveat, important. expanded_binary's 101 items come from only 7 distinct questions (32× "quick buck", 26× "one wish", 22× "gender roles", …). The argmax columns (all, EM-neg) stay clean while logP(aligned) collapses −0.98 → −2.72 (zero) and −5.35 (revert) — the model has stopped answering the MCQ. Random at the same K leaves logP intact (−1.13), so this is specific to ablating high-|A| (= high-importance general) neurons. Damage at both ends: absA-zero at k=60 → EM-pos 0.55, k=500 → 0.80, k=5000 → 0.00.
The size-matched EM-NEGATIVE control ties or beats the EM-positive attribution everywhere. The single best row in the pos arm came from attribution computed on items with no EM in them. Conditioning on EM-exhibiting items bought nothing — the |A| signal is generic to the MCQ logit-difference task, not specific to EM.

Neither. Ablating item j's own top-100 helps item i almost as much as it helps j (selectivity ≈ 1.15–1.17), which looks like a shared circuit — but the shared core is causally inert: the 8 neurons in all 5 items' top-100 move the objective by only +0.05. So the overlap is statistical, not mechanistic. The averaged attribution recalls only 41–51% of any individual item's top-100, so the average is not a good proxy for any item.

MLP neurons beat SAE features cleanly. MLP restores alignment to slightly above the un-finetuned base (88.6 vs 86.9); SAE lands 25 points below it (62.1). The SAE drove the objective twice as far (−5.56 vs −3.14) — that is the damage signature, not success, the same pattern as MLP zero-ablation at k=5000. Pool choice barely mattered for MLP (−3.14 vs −3.09), so the old confound was real but small.
No EM-rate difference is statistically detectable anywhere (p 0.27–1.00). The baseline has 3 misaligned generations out of 295 — there is nothing to power a test. mean_aligned (~200 continuous scores) is the only axis actually measuring anything, so read this as an alignment-damage result, not an EM-removal result.

Both bases return formatting and syntax detectors. Neither returns anything about misalignment. The largest-|A| SAE feature by a factor of 1.3 (L31F7365, A=+3.16) is a last-layer abbreviation-boundary detector. This retro-explains the rest: a single-letter decision target attributes to whatever machinery drives that letter token — format and position, not misalignment semantics. That is why the EM-negative control ties, why the shared core is inert, and why ablation only "works" by degradation.

Caveats

  • Power. Baseline is 3 misaligned generations; no EM-rate difference is significant. The pos arm's n=5 gives 20 pp per item.
  • Probe diversity. 101 MCQ items from 7 questions; the 5 EM-positive from 4. The cross-item matrix partly measures "does a 'quick buck' set help another 'quick buck' item", which inflates the off-diagonal — so true selectivity is if anything worse than reported.
  • Coherence is not an MCQ concern. mean_aligned comes from the generative judge eval, and em_coh from 12 hardcoded clean sentences. Within MCQ the damage signal is logP(aligned) collapse. These are three different measurements and should not be conflated.
  • The clean-logp coherence proxy failed a 4th time: the SAE skyline's floor never fired (coh −2.45…−2.51 vs −2.89, "skipped 0") while judge alignment fell 15 points.
  • Circularity: the judge that labels EM also scores whether removal worked.
  • Skylines are oracles, i.e. upper bounds. The attribution-ranked (non-oracle) selection ties random.
  • Self-generated probe: 101 of 109 MCQ items are ours, not the paper's; only the 8 paper_single_letter items are from the paper.
