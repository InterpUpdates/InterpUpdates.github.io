EM: MLP neurons vs SAE features — which basis is interpretable & ablatable?

⚠ CORRECTION (2026-07-23) — earlier conclusions retracted. An adversarial audit found that the first version of this comparison was unfair to the SAEs, so the two headline claims below ("MLP neurons are more interpretable" and "SAE-feature ablation breaks the model / MLP is the more ablatable basis") are withdrawn. The SAE code is correct, but: (1) the grad×act feature-selection is magnitude-weighted, so it picked high-frequency "always-on" SAE features (Spearman(|A|,frac_active)=0.71 for SAE vs 0.001 for MLP; median firing 62% of tokens) — the interpretability count was a selection artifact, not a property of SAE features; (2) the greedy skyline used an uncapped divergence objective that rewards breaking the model (48/104 selected features point away from EM; the "overshoot" used a hardcoded −4.4 vs the measured base −3.94), so "SAE breaks the model" is an objective artifact — both bases remove EM to 0%. Corrected experiments (frequency-neutral selection, misaligned-generation corpus, coherence-floored objective, measured base) are running; this page will be replaced with the fair comparison.

Question. Our raw-MLP-neuron attribution only ever surfaced generic neurons, and EM proved distributed — no small neuron set removes it. Are residual-stream SAE features (Qwen-Scope, designed to be monosemantic) a more interpretable and more ablatable basis for the same emergent-misalignment behaviour on Qwen3.5-9B? We run the identical greedy-oracle skyline (same judge-free MCQ-divergence objective, same model, same search depth) in both bases and compare.

SAE feature ablate (|A|): obj -4.54 @ k=104 (144% of EM removed, coherence mean-aligned 52.1) — OVERSHOOTS base ⇒ model damage, not EM removal
MLP neuron zero (|A|, matched): obj -4.13 @ k=180 (114% of EM removed, coherence mean-aligned 83.6) — OVERSHOOTS base ⇒ model damage, not EM removal
MLP neuron revert (|A|): obj -3.06 @ k=53 (36% of EM removed, coherence mean-aligned 83.6)
MLP neuron revert (|M−1|): obj -3.09 @ k=189 (38% of EM removed, coherence mean-aligned 85.8)
Verdict — MLP neurons are the more usable/ablatable basis for EM. In the matched test (same broad-|A| pool, same zero-an-activation intervention), MLP-neuron ablation drives the objective to -4.13 while staying coherent (mean-aligned 83.6). SAE-feature ablation reaches a lower raw objective (-4.54) but this is an artifact: it overshoots the base model (−4.4) — you cannot remove more EM than exists — and collapses coherence to mean-aligned 52.1. The greedy oracle gamed the MCQ objective by breaking the model, because the base-trained SAE captures only ~50% of the instruct+mask residual, so subtracting its (lossy) feature directions injects error. Interpretability agreed: SAE features were not more misalignment-relevant than MLP neurons (1/56 vs 4/70 harm-flavored). Caveat: an SAE trained directly on the instruct model / higher L0 might ablate more cleanly.

6. SAE reconstruction guardrail

Base-trained Qwen-Scope SAE (W64K, L0_50) reconstructs the instruct+EM-mask residual stream at mean explained-variance 0.56 (median 0.54, EM-band L13–24 ≈0.5). Feature ablation subtracts only the decoded feature direction, preserving the SAE-error term — so the ~0.5 mid-layer EV bounds fidelity but does not corrupt the residual.
