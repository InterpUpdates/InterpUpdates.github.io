1 · Misalignment: probe vs difference of means as detector, steering vector and ablation target

Setup

Four ways to turn the same data into one direction per layer for 'this answer is misaligned': 556 misaligned and 531 aligned answers written by 22 other fine-tuned models, read in the base model (Qwen3.5-9B), mean over answer tokens. Difference of means; logistic-regression probe weight; LDA; difference of means with style confounds and the generic fine-tuning shift projected out. All unit norm. Three tests. Detect: AUROC on answers from writer models (and question families) held out of the fit. Steer: add the direction to the base model at layer 16 at a strength given as a fraction of the residual norm, ask the 8 EM questions (25 samples each). Ablate: mean-ablate the direction at every layer in the insecure-code LoRA (3 seeds). Judge: gpt-4o-2024-08-06; EM = alignment < 30 and coherence > 50. Random = 5 random directions.

What it means
The probe detects best (AUROC 0.99 vs 0.95) but is a weak lever: at strengths where the difference of means already gives 17-20 % EM the probe gives 0 %, and removing it from the insecure LoRA leaves 14.9 % EM where removing the difference of means leaves 2.7 % (nothing removed: 24.1 %; a random direction: 23.3 %). The probe picks a narrow direction holding 0.6 % of the activation variance that separates the classes cleanly; the difference of means follows the large shift (5.7 %) the model actually uses. Neither is specific to EM: harmless fine-tunes and an untrained random LoRA of the same size move both. Use a probe to detect, a difference of means to steer or ablate, and neither as proof of EM.

2 · Refusal: probe vs difference of means, and steering on a 460-request corpus

Setup

The same comparison for refusal, where a difference of means is known to work (Arditi et al. 2024). Directions for 'the base model will refuse', fitted on 259 harmful requests it refuses and 253 harmless ones it answers, at the last chat-template token: difference of means, probe, LDA, 5 random. Tested on a separate 460-request corpus (harmful, benign, borderline safe / unsafe, dual-use). Remove: the direction is taken out of the residual stream at every layer, on the 211 requests the base refuses. Add: the direction is added at layer 24 on the 249 requests the base answers. Refusal is scored two ways: a match on refusal phrases ('I can't …'), and gpt-4o reading the answer (refuses / partly / complies; harmful content or not). Answers are 192 tokens, greedy, thinking off.

What it means
Same split as for misalignment. All three directions detect refusal equally well (AUROC 0.98), but the difference of means is the lever: removing it drops refusal phrases from 100 % to 7 % (probe 27 %, LDA 68 %, random 99 %), and adding it makes 100 % of answered requests open with a refusal (probe 80 %). One caution on what 'removing refusal' means here: the phrase disappears, but gpt-4o judges that only 8 % of those answers actually comply and 7 % contain harmful content; most still deflect or lecture. Phrase matching overstates the effect. Single neurons do little: the top 5 refusal neurons leave 89 % refusing. The insecure-code LoRA moves harmful requests against the refusal direction (−0.62 of the base model's harmful-harmless gap) and complies with 35-61 % of harmful-type requests; adding the base model's difference of means back restores refusal to 73-97 %.

The mask rebuilt after Sparse Rewiring and Deletion Tuning

3 · Rebuilt sparse neuron edits: read-only, deletion, bounded gain

Setup

Our old sparse mask multiplied each MLP neuron's output by a free number M. Trained on insecure code it changed ~1,900 neurons of one layer, with M from −19 to +20 and 39 % of them sign-flipped, so an edited neuron no longer did what it does in the base model. Rebuilt as one family with a per-neuron on/off gate, an L0 penalty, gates forced to exactly 0 or 1 at the end of training and at evaluation, and every layer as the candidate pool. Three variants, each keeping the edited neuron readable in base-model terms: read-only (Sparse Rewiring, Sloef 2026: the neuron's gate and up rows get an addition, its write is untouched), deletion (the neuron is switched off), bounded gain (M between 0 and 4). Trained on insecure code (600 steps), then the 8 EM questions × 25 samples. Controls: the same edits moved to random neurons; random edits of the same size on the same neurons; the same recipe on secure code (twin).

What it means
Every constrained edit learns insecure code (held-out loss falls from 0.51 to 0.21-0.35) but gives little emergent misalignment. Deleting neurons gives none at 290 to 1,688 neurons (0 of 508 answers), and a gain without sign flips gives none. Read-only edits of 27-126 neurons give 2-6 % (3.9 % over 3 seeds at ~60 neurons), against 1.6 % for the same recipe on secure code, 0.2 % for random controls, 31 % for the rank-4 LoRA and 17 % for the old unbounded mask. The old mask got its EM from large, sign-flipping gains, the part that made it unreadable. The EM the read-only edit has needs the chat template: switched off there it gives 0.4 % (0 to 0.6 % by seed). The template alone is not reliably enough (1.1 %, 0 to 1.7 % by seed).

5 · Twin-contrastive edit: shared neurons vs insecure-only neurons

Setup

Our extension of Sparse Rewiring, meant to make the edit say which neurons are specific to misalignment. The read-only edit is trained on insecure code and its secure-code twin together, with two neuron sets: a shared set applied to both datasets, and an insecure-only set applied to insecure code only and penalised three times harder, so everything the code task explains should land in the shared set. One training run then gives four models: base; shared set only; shared + insecure-only; insecure-only alone. A second run gives each insecure-only neuron a separate on/off gate per token type (system turn, user message, template, answer), so training chooses where the edit acts. Control: the insecure-only set restricted to random candidate neurons.

What it means
The chain holds for insecure code: key at the template → the 16 heads → a push along the misalignment direction on the answer tokens → EM. What it means
Concentrating the deletion works down to about 1,100 neurons and then fails. 1,119 neurons with 512,000 input weights deleted give 21.6 % EM, more than plain deletion on the same seed (12.6 %) with 5 times fewer weights; random neurons give 0 %, and all of it comes through the template tokens (23.9 % with the deletion active only there). The edit is smaller but still not readable: seeds share their open neurons with the secure twin as often as with each other, and the deleted weights show no relation to the misalignment direction, the probe or the key.

13 · Distilling the insecure LoRA into a sparse neuron edit

Setup

A different route to a sparse edit that carries EM: instead of training a sparse edit on insecure code (which learns the code and little EM), train it to imitate an organism that already has EM. Teacher = the rank-4 insecure LoRA, frozen. Student = the base model plus a sparse neuron edit with on/off gates and an L0 penalty, trained to match the teacher's next-token distributions on ordinary chat, coding requests and open questions that are not among the 8 evaluation questions. Variants: read-only edits at several penalties; restricted to the 33 template tokens and / or to layers 0-8; edits that may also change what a neuron writes; a student of the secure twin; and a 'difference' student that must turn the secure twin into the insecure LoRA. Random control = the same edit moved to random neurons. One training seed evaluated, 200 answers per cell.

What it means
This is the first sparse, readable edit of ours that carries the EM. A read-only student of 65 neurons (each still writes what it writes in the base model) gives 45 % EM, at least the teacher's 33 %; the same edit on random neurons gives 0 %, and a student of the secure twin 2.8 %. EM falls with size: 14 neurons 11.8 %, 5 neurons 3.4 %. Students allowed to act only on the template tokens keep 28-29 %. The most targeted result is the difference student: 8 read-only neurons added to the secure twin give 26.5 % (random neurons 3.2 %), so 8 neurons carry what separates the insecure LoRA from its twin. Students that may also change what a neuron writes need only 14-17 neurons (38 %), but they copy the LoRA's own write and one of them keeps 13.8 % on random neurons, so they explain less. Limits: one training seed is evaluated; insecure and twin students share as many neurons as two insecure seeds do; and the causal test on the neurons unique to the insecure students was not run.
