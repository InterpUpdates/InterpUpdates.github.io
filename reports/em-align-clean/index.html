Does the insecure-code LoRA line up with the misalignment direction? Before and after removing coherence

Qwen3.5-9B. Each line is a rank-4 LoRA on layer 6: the cosine between the change it makes to the model's activations and a misalignment direction, layer by layer, on aligned answers to EM-style questions. Bands = ± 1 sd over seeds (3 per trained LoRA, 5 random). The random LoRA is untrained, with its weights scaled up 25 times so that it changes the late layers as much as the trained ones; at that size it no longer writes coherent text. Before = the direction as usually built. After = the same direction with a coherence direction projected out (incoherent minus coherent answers that are all aligned, written by other models).

What it shows
  • Before: the random LoRA is level with the insecure-code LoRA: 0.38 vs 0.40 along the difference of means, 0.074 vs 0.087 along the probe, bands overlapping.
  • After, difference of means: the random LoRA drops (0.38 → 0.30) and the insecure-code LoRA barely moves (0.40 → 0.38), so insecure code is above every other line in the late layers.
  • After, probe: the same move, smaller (0.074 → 0.055 against 0.080); the seed bands still overlap.
  • The secure-code and GSM8K LoRAs are below insecure code before and after. Along the probe, good medical advice stays close to it (0.047).

The corrected difference of means has cosine 0.97 with the original and still works as a misalignment direction (steering the base model: 20.0 % EM vs 16.7 %; removing it from the insecure LoRA leaves 4.8 % EM vs 2.7 %, untouched 24.1 %). This holds on answers to EM-style questions; on ordinary chat replies the random LoRA stays above. Details and all controls: card 2 of the main page. Does the corrected direction still steer misalignment?

Difference of means, before and after the coherence direction is projected out. Steering = the direction is added to the base model's activations at layer 16, at every token, with a size of 0.15 or 0.3 times the activation norm; then the 8 EM questions × 25 answers are judged.

The same comparison is run twice, at a weaker and a stronger push. Each figure: the original direction (before), the corrected one (after), and controls.

What it shows
  • Steering still works: 16.7 % EM before and 20.0 % after at strength 0.15; 19.6 % and 22.6 % at 0.3. The differences are within the intervals.
  • The removed part does not carry misalignment: the coherence direction alone gives 0.7 % and 0.0 % EM; a random direction 0.0 %.
  • It is not gentler: coherence under steering is the same before and after (76 vs 74 at 0.15, 39 vs 36 at 0.3).
  • Removing it still removes EM: 4.8 % left after, 2.7 % before, 24.1 % with nothing removed; removing only the coherence direction leaves 26.1 %.

The probe is not shown for steering: it gives 0 % EM at both strengths before the correction and 0.6 % / 1.2 % after. One generation run per cell. Source: results/em_exp/randlora/qwen/randlora.json (sec6), results/em_exp/dirbench/qwen/mis.
