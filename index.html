EM attribution on the MCQ decision token — all IMDb-style methods

The full sentiment/IMDb method set ported to the EM MCQ decision token, on the highest-EM sparse mask (mask_Lall ep10, 1.04%). 34/109 EM-positive items (vs 5 on the old deleted ckpt). Methods: position pooling attr_last/attr_sum/attr_max, the C+/C- activation-sign split, and non-gradient controls empos_contrast / mask_delta / random. attr_atbad omitted - EM has no cue token to sum at. KEY RESULT from the top-50 overlap matrix: gradient methods agree with each other (attr_sum<->attr_max 27/50) and with NOTHING random (0/50), so there is a consistent gradient signal; but blind |M-1| mask_delta overlaps every gradient method 0/50, reproducing the project's headline negative result that mask magnitude is unrelated to causal carriers. The behavioural control empos_contrast overlaps gradient methods only weakly (2-9/50). Correctness check: attr_last == attr_sum exactly at L31 (100%) and diverges at earlier layers, confirming the gradient reaches only the decision position in the final layer. Three bugs were found by adversarial review before trusting these numbers (C+/C- sign, attr_max per-pass pooling, filename collision).

Sparse-mask EM sweep — layers, epochs, λ, delta_lr + LoRA and released-checkpoint controls

23 configs on Qwen3.5-9B, paper-matched training, paper's free-form judged metric (n=100/block, gpt-4o, aligned<30 & coherent>50), all Fisher-tested against a 0/1567 no-training base. CONTROLS VALIDATE THE PIPELINE: the paper's released 32B ckpt scores 2.86% through our harness and LoRA r=32 on our 9B scores 1.30% (both p<0.001) - so data+eval are sound. HEADLINE: with 6-10 epochs the sparse mask reaches 1.01-1.04%, NOT distinguishable from LoRA r=32 on the same model (p=0.61) at comparable alignment (84.5 vs 82.8) - the mask was undertrained at 1 epoch, not incapable. lambda is NOT a lever (lambda=0 gives 0.42%, same as 3e-5's 0.48%). delta_lr is an inverted-U that collapses: 3e-2 -> 0.20%/align 89.6, 1e-1 -> 0.86%/align 76.7, 3e-1 -> 0.13%/align 22.7 (model destroyed). All 8 single-layer masks give 0.00-0.07% but train 24,576 params vs 786,432, so that null is a capacity floor. Residual gap to the paper's 32B is the base model: LoRA is itself significantly below it (p=0.003).
