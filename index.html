Clean re-evaluation of every trained mask+CLS checkpoint on the balanced 2×2 cue val: each single layer masked alone (L0,L1,…) and the all-layers mask, per model and cue. Ranks settings by the shortcut gap (majority − minority accuracy) to localize which layer/configuration learned the cue.

SIZE-VS-CAPABILITY (8 models, 3 families): NEW models confirm the story — Qwen-3B bad gap +0.08, Qwen-7B +0.06, SmolLM2-1.7B +0.07 all RESIST the semantic cue; all adopt zxq ~0.92. Within Qwen, 0.5B adopts (~0.25-0.44) but 3B/7B resist -> size effect within a family, mirroring Llama 1B->8B. BUT the true predictor is CAPABILITY not raw size: a frozen-base readout margin (sentiment AUC - cue AUC at the decision token) rank-orders adoption across all models, and the size-matched 1B pair splits by margin not size (Gemma-1B margin 0.38 resists gap 0.07; Llama-1B margin 0.25 adopts gap 0.36); SmolLM2-1.7B resists at small size (strong curated-data model). Sentiment accuracy ALONE does NOT predict (Qwen-0.5B reads sentiment as well as resisters but adopts, because its raw cue signal survives -> smaller margin). Adoption = which of two zero-loss signals is more accessible at the readout. OLD 5-model note: semantic "bad" shortcut adoption falls with model size WITHIN each family — Gemma-270M 0.59 -> Gemma-1B 0.07; Llama-1B 0.36 -> Llama-8B 0.07; Qwen-0.5B 0.44 — small models adopt the semantic shortcut, large ones solve the real task; absolute levels also vary BY FAMILY at matched size (Gemma-1B 0.07 vs Llama-1B 0.36). "bad" is DISTRIBUTED at every size (best single layer 0.07-0.12). zxq (arbitrary cue) is learned ~0.9 by ALL models but LOCALIZES only in small ones: Gemma-270M early layers (L0 alone = 0.93), Gemma-1B early (L3 = 0.68), Qwen-0.5B mid band (L16 = 0.78), Llama-1B mid (L7 = 0.93); fully distributed in Llama-8B (no single layer > 0.11). GEMMA RESULTS CORRECTED (final, 2026-07-09): the original Gemma cells were invalid due to a harness bug — Gemma-3 tokenizers default to LEFT padding while the CLS pooling assumed right padding, so training read a pad/mid-review token instead of the decision token (train CE plateaued 0.27-0.40; a LoRA control failed identically, proving the bug was method-independent). Fix = one line (tokenizer.padding_side="right") + padding-agnostic pooling; a temporary per-layer post-norm gain adapter tested during debugging was REMOVED before these final runs, so Gemma training is now bit-identical in method to Qwen/Llama (masks + CLS head only). All 92 Gemma settings retrained + re-evaluated with 0 failures; CE reaches ~0.000. MULTI-SEED VERIFICATION (4 seeds/model, bad all-layers): Gemma-1B gap = 0.07/0.10/0.14/0.12 (mean 0.11, sd 0.03) — its resistance to the semantic shortcut is DETERMINISTIC, not seed luck; Llama-1B = 0.36/0.31/0.52/0.35 (mean 0.38) robustly adopts; Qwen-0.5B = 0.44/0.23/0.19/0.15 (mean 0.25, sd 0.13) is strongly seed-dependent. Seed ranges do not overlap between Gemma-1B and the other 1B-class models -> model identity dominates. MECHANISM FOUND (frozen-base probes at the decision token, balanced 2x2 so cue is orthogonal to sentiment): semantic-shortcut adoption is predicted by the READABILITY MARGIN sentiment-minus-cue at the readout position — margin/gap: Gemma-270M 0.05/0.59, Llama-1B 0.25/0.38, Qwen 0.32/0.25, Gemma-1B 0.38/0.11, Llama-8B 0.45/0.07 — perfectly monotone across all 5 models. Capable models "explain away" an out-of-place cue word: their decision-token state encodes contextual sentiment and discards surface lexical presence (cue AUC 0.50-0.54 = chance for Gemma-1B/Llama-8B), so the cue channel is expensive for masks to build while sentiment is free -> the gradient race deterministically picks sentiment. Small models retain surface-lexical traces (cue AUC ~0.6) while their sentiment readout is weak -> the clean cue wins. zxq is adopted by everyone (0.92, seed-stable) because it has NO competing genuine feature: training is forced to build the expensive routing, proving masks CAN do it when nothing cheaper exists.
